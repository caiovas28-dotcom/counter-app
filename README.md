# Contador

## Autor
Desenvolvido por Caio Duraes Vasconcelos

---

## Descrição

Este é um projeto simples de contador desenvolvido com HTML, CSS e JavaScript.

O objetivo foi praticar manipulação do DOM, lógica de programação, eventos e armazenamento local no navegador (LocalStorage).

O projeto permite incrementar, decrementar e resetar valores, além de suportar valores negativos e alternar entre tema claro e escuro.

---

## Funcionalidades

- Incrementar e decrementar valores
- Reset do contador
- Permite números negativos
- Modo claro/escuro
- Salvamento automático com LocalStorage
- Animação ao atualizar o valor

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
